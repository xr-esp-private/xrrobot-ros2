# guard — 雷达警戒

## 能力
通过激光雷达检测入侵者。人进入雷达 1m 范围内触发声音报警，退出后停止。

## 启动
```bash
ros2launch xrrobot_follower radar_guard.launch.py
```

## 调用
启动后自动工作。不需要额外调用。

## 依赖
| 需求 | 说明 |
|------|------|
| launch | `radar_guard.launch.py` |
| 前置 | 需要雷达在线 |
| 含 | 声音模块（全包） |

## 兼容性
| 可共存 | 说明 |
|--------|------|
| ✅ camera | 可同时看画面 |
| ✅ 任何不占底盘的 | 警戒不控制底盘，仅检测报警 |
