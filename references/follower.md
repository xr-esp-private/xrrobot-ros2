# follower — 雷达跟随

## 能力
机器人通过激光雷达识别前方人体，自动跟随移动。

## 启动
```bash
ros2launch xrrobot_follower laser_follower.launch.py
```

**安全提示**：

- 启动后机器人可能自动开始跟随前方目标移动
- 执行前先确认机器人前方和侧方区域已清空
- 需要有操作人员在现场监护，并能随时介入停止
- 不要在狭窄通道、人群附近、易碰撞环境中直接启用

## 调用
只有在用户明确同意、且现场确认安全后，才让人站到雷达前方触发跟随。
启动后机器人可能自动工作并跟随前进。
可通过 RViz2 看到跟随时的人体位置：
```bash
rviz2 -d ~/Desktop/laser_follow.rviz
```
